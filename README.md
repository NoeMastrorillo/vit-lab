# ViT Lab

Experiments with Vision Transformers.

## Projects

1. [`ViT from scratch`](1-vit-from-scratch/README.md): a Vision Transformer implemented in PyTorch, including multi-head self-attention, and trained on CIFAR-10. Compares the effects of dropout and data augmentation on a 1.07M parameters model, raising test accuracy from 68% to 79.7%.
